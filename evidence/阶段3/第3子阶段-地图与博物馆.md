# 阶段 3 · 第 3 子阶段（地图可视化增强 + 博物馆）证据包

> 项目：中国艺术史时空地图
> 交付日期：2026-09-26
> 需求：1) 中国地图可视化在界面上显示；2) 加入每个艺术中心现在存在的艺术博物馆

## 一、本子阶段做了什么

1. **离线 SVG 中国地图兜底**：
   - 内置简化后的中国省界 GeoJSON（`src/data/china.json`，34 省级行政区，简化到 27KB）
   - 新增 `SvgChinaMap` 组件 + `geoProject` 投影工具：百度地图加载失败/未配置 AK 时，自动切换为自绘 SVG 中国地图，省界 + 气泡 + 轨迹线完整保留
   - **修复空 AK 弹窗**：index.html 改为「有 AK 才注入百度脚本」，否则直接走离线地图，不再触发百度报错弹窗
2. **博物馆数据**：13 座城市各补充现在可参观的博物馆（陕西历史博物馆、故宫博物院、南京博物院、上海博物馆等），详情面板新增「今日可看 · 博物馆」区块
3. **顺带修复**：轨迹线描边动画此前 `pathLength` 写在了 CSS（无效），改为 SVG `pathLength={1}` 属性，动画真正生效
