## 二、产品经理自己照着点

1. 打开终端进入前端目录，启动：
   ```bash
   cd docs/中国艺术史/frontend
   npm run dev
   ```
2. 浏览器打开 `http://localhost:5173`（若端口被占用看终端提示的实际端口）。
3. 应看到：中国地图 + 底部「唐…清」时间轴 + 右侧「唐」侧栏 + 地图上西安/洛阳/敦煌/成都四个彩色气泡（默认唐）。
4. 点底部「南宋」→ 气泡变成杭州（红）/苏州（蓝），虚线轨迹线从西安一路长到杭州。
5. 点「杭州」气泡 → 弹出详情面板：南宋背景 + 宫廷画派 + 代表画家（李唐/刘松年/马远/夏圭/梁楷）。
6. 键盘 ← → 可切朝代；手机宽度（<640px）下地图/信息区/时间轴纵向堆叠。
