# 第 1 阶段前端开发文档（MVP v0.1）

## 1. 本阶段目标
- 用户打开网页，拖动底部朝代时间轴，就能看到中国地图上艺术中心气泡随朝代变化、轨迹线一路往南生长；点任意气泡，看到这个城市的时代背景、画派和代表画家。

## 2. 范围
### 本阶段包含
- 页面：单页应用（地图 + 时间轴 + 侧栏 + 详情面板 + 图例）
- 组件：MapCanvas、Timeline、InfoPanel、DetailDrawer、Legend、useDynasty
- 功能：F01 地图初始化、F02 个性化底图、F03 时间轴切换（含键盘←→与滑动）、F04 气泡渲染、F05 过渡动画、F06 迁移轨迹线、F07 图例、F08 详情面板、F09 侧栏、F10 画家索引
- 数据：7 朝代、12+ 城市、约 30 个艺术中心、约 30 位画家（含生卒年/代表作/收藏机构）

### 本阶段不包含
- F11 行程模式、F12 分享海报（P1）；F13 AI 讲解、F14 附近展览（P2）
- 用户系统/登录/收藏；作品高清图；后端/数据库

## 3. 用户流程
1. 打开页面 → 默认定位「唐」，地图渲染西安/洛阳/敦煌/成都气泡，侧栏展示唐代叙事
2. 点/拖/键盘←→切换朝代 → 气泡按新朝代数据过渡（0.55s），轨迹线生长，侧栏同步
3. 点击某城市气泡 → 详情面板弹出（朝代背景 + 画派 + 代表画家 2–3 位）
4. 详情内展开画家索引 → 看生卒年、代表作、收藏机构

## 4. 页面状态矩阵
| 模块 | 初始 | 加载 | 空 | 成功 | 失败 |
|---|---|---|---|---|---|
| 地图 | 占位底图 | JSAPI 加载中 | — | 渲染气泡/轨迹 | 加载失败提示 + 重试按钮 |
| 时间轴 | 7 朝代，选中「唐」 | — | — | 可切换 | — |
| 侧栏 | 唐代叙事 | — | — | 当前朝代信息 | — |
| 详情面板 | 关闭 | — | 该地无画家数据 | 展示详情 | — |

## 5. 接口契约
- 无后端接口。数据为本地静态 JSON（dynasties/places/centers/figures），构建时 import + 运行时 schema 校验。

## 6. 实现方案
- 路由：无路由，单页 App.tsx
- 组件结构：App → MapCanvas + Timeline + InfoPanel + Legend + DetailDrawer（按 PRD 7.3 目录）
- 状态来源：useState 存 currentDynasty；派生数据（当前朝代 centers/figures）用 useMemo
- 响应式：断点 640px，宽屏「地图+右侧栏」，窄屏纵向堆叠
- 安全：百度 AK 存 `.env`（`VITE_BAIDU_AK`），不入仓库；Referer 白名单在百度控制台配置；服务端 AK 严禁入前端
- 坐标：数据入库前统一转 BD-09，JSON 中 `coordSystem: "BD09"` 标注并加载校验

## 7. 验收标准
- 自动检查：`npm run lint` / `npm run typecheck` / `npm run test` / `npm run build` 全通过
- 浏览器人工检查：390/768/1280/1440px 四档；Console 无报错；朝代切换动画流畅；点气泡出详情
- 数据校验测试：7 朝代齐全、centers 坐标均为 BD09、weight∈[0,1]、type∈四类、narrative 80–120 字

## 8. 风险与回退
- 风险：百度 AK 未配置时地图白屏 → 回退：.env 缺 AK 时显示「地图未配置」提示，页面其余部分仍可预览
- 风险：坐标未转 BD-09 导致偏移 → 回退：加载时校验 coordSystem，非 BD09 拒绝渲染并提示
