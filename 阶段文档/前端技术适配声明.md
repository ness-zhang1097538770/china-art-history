# 前端技术适配声明

> 项目：中国艺术史时空地图
> 日期：2026-09-23
> 依据：PRD v0.1 + 《通用前端技术栈手册》+《技术适配声明》

## 1. 项目判断
- 产品类型：可视化内容产品（时间 × 空间双轴叙事的中国艺术史地图），非 Agent 产品
- 主要用户：艺术/人文爱好者（主力）、学生、文旅人群
- 主要终端：移动 Web 优先 + 桌面 Web（响应式）
- 新项目或已有项目：新项目
- 本阶段业务目标：MVP v0.1 —— 拖动朝代时间轴，看艺术中心气泡/轨迹线变化，点气泡看详情

## 2. 输入资料
- PRD：已读取（v0.1，377 行，完整）
- 后端手册：已读取（通用手册第一至六节；本产品无后端）
- 接口文档：N/A（纯前端，无后端接口）
- 设计稿：无 → 视觉方向由 PRD 指定（古地图/绢帛/水墨质感 + 四色画派配色）
- 现有代码：无（新项目）

## 3. 技术选择
- 框架与版本：Vite + React + TypeScript strict（PRD 指定；纯静态无 SSR 需求）
- 样式与组件策略：Tailwind CSS 4 + CSS 语义变量（PRD 四色 + 绢帛底色）；组件先自建（时间轴/图例/详情面板/侧栏均为轻量组件）
- 数据请求与状态策略：无网络请求，静态 JSON 随包 import；全局状态仅 currentDynasty 一个，用 useState + context 派生当前朝代数据
- 流式通信策略：N/A（无流式）
- 表单方案：N/A（无表单）
- 测试方案：Vitest（数据 schema 校验 + 状态映射单测）＋ 浏览器人工检查
- 部署环境：腾讯云 EdgeOne Pages 静态托管

## 4. Agent 状态
- 不适用。本产品无后端任务/Agent，无 loading/waiting/流式/断线恢复；仅地图 JSAPI 加载失败需要兜底提示（加载失败态）。

## 5. 页面与产物
- 核心页面：单页 —— 地图 + 底部朝代时间轴 + 侧栏信息区 + 详情面板 + 图例
- 核心业务闭环：进入页面（默认唐）→ 拖/点时间轴 → 气泡过渡 + 轨迹线生长 + 侧栏同步 → 点气泡看详情
- 产物类型：可视化交互页（无下载产物）
- 响应式目标：390 / 768 / 1280 / 1440px；<640px 时地图/信息区/时间轴纵向堆叠

## 6. 偏离本手册的地方
| 偏离项 | 原因 | 影响 |
| --- | --- | --- |
| 默认 Next.js App Router → Vite + React SPA | PRD 明确指定；纯静态、无 SSR/SEO 刚需 | 无后端路由、无 API 代理需求 |
| Agent 状态模型（第 9 节）不适用 | 非 Agent 产品 | 只需地图加载/失败两个额外状态 |
| 流式输出/用户确认/API 契约章节不适用 | 无后端、无流式、无表单 | — |

## 7. 待确认事项
- 无。决策台账中影响前端的待定项已全部关闭；视觉方向 PRD 已明确（古地图质感 + 四色画派）。
