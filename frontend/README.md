# 中国艺术史时空地图 · 前端

「一张会随时间变化的地图」——拖动底部朝代时间轴，看中国艺术中心气泡与迁移轨迹线随朝代变化，点气泡看该地时代背景、画派与代表画家。

## 功能

- 中国地图可视化：**接入百度地图 JavaScript API 2.0（图片瓦片版，兼容所有浏览器）**作为主底图（比赛要求），内置自绘 SVG 中国地图作为兜底（百度地图无法加载时自动切换）
- 朝代时间轴（唐/五代/北宋/南宋/元/明/清），支持点击、键盘 ← →、移动端滑动
- **自动播放**：点 ▶ 朝代自动前进，气泡与轨迹线动起来，看完「中心南移」全程
- 艺术中心气泡（半径/透明度随活跃度权重），迁移轨迹线描边生长动画
- **主线导读**：可展开的「为什么一路往南」面板，讲清政治/经济/文化三条逻辑
- **全局搜索**：搜画家/城市/画派，点结果直接跳转对应朝代与城市
- **画派筛选**：点击图例类型，气泡按画派过滤（只看宫廷/文人/宗教/市民）
- 详情面板：该地画派介绍 + 时代背景 + 代表画家（生卒年/代表作/收藏机构）+ **今日可看的博物馆**
- **AI 讲解**：点城市可生成口语化讲解词（常规/细一点/给孩子听），并用阿素音色朗读
- **分享海报**：一键生成「我在某朝代的某城」卡片，保存图片 / 系统分享
- 响应式：<640px 地图/信息区/时间轴纵向堆叠

## 技术栈

- Vite + React 19 + TypeScript（strict）
- Tailwind CSS 4
- 百度地图 JavaScript API 2.0（图片瓦片版，非 WebGL，兼容所有浏览器）
- Vitest（数据校验 + 状态映射单测）

## 启动前准备

1. 申请百度地图 Web 端 AK（百度地图开放平台 → 控制台 → 创建应用，类型选「浏览器端」）。
2. 在该应用下配置 **Referer 白名单**（本地开发临时填 `localhost`，上线后改成你的域名）。
3. 复制 `.env.example` 为 `.env`，把 AK 填到等号右侧：

```bash
cp .env.example .env
# 编辑 .env：VITE_BAIDU_AK=你的AK
```

> `.env` 已被 git 忽略，不要提交到仓库；也**严禁**把服务端 AK 写入前端。

## 安装与启动

```bash
npm install        # 首次
npm run dev        # 启动开发服务器（默认 http://localhost:5173）
```

### 启动 AI 讲解后端（可选，用 AI 讲解功能时才需要）

AI 讲解需要后端代理硅基流动的大模型/语音合成调用（API Key 不进前端）。

```bash
cd ../backend
cp .env.example .env   # 填入 SILICONFLOW_API_KEY
node server.mjs        # 启动在 http://localhost:3002
```

## 验证方法

自动化检查（四项全过才算通过）：

```bash
npm run lint       # oxlint
npm run typecheck  # tsc -b
npm run test       # vitest（9 个用例）
npm run build      # tsc -b && vite build
```

浏览器人工检查：

1. 打开 dev 地址，地图应加载出中国全境，默认「唐」渲染西安/洛阳/敦煌/成都四个气泡。
2. **验证离线兑底**：临时删除 `.env` 重启，页面应显示「离线地图模式」+ SVG 中国地图（不弹百度报错窗），气泡仍可点击。
3. 点底部朝代 / 按键盘 ← → / 移动端横向滑动，气泡与侧栏叙事应随朝代切换，轨迹线逐段描边生长，地图平移到当前主中心。
4. 点 ▶ 自动播放：朝代每 2.5s 自动前进，到「清」后自动停止。
5. 点右侧「为什么一路往南」展开主线导读；点任意气泡看详情：该地画派介绍 + 代表画家 + 今日可看的博物馆。
6. 顶部搜索框搜「马远」或「苏州」或「文人」，点结果跳转；点图例类型可筛选气泡。
7. 点右上角「分享」生成海报，可保存图片 / 系统分享。
8. 分别用 390 / 768 / 1280 / 1440px 宽度查看：<640px 时地图/信息区/时间轴纵向堆叠。

## 数据

静态数据在 `src/data/`：

- `dynasties.json` / `places.json` / `centers.json` / `figures.json`：朝代、城市、艺术中心、画家（含博物馆、画派介绍）
- `china.json`：简化后的省界 GeoJSON（离线 SVG 地图用）

坐标统一为 BD-09（`coordSystem: "BD09"`），启动与测试时会做 schema 校验。
